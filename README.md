> Browser Extension for saving code snippets, quick links, and developer notes directly from your browser toolbar.

---

## 🌟 Features

- **⚡ Chrome Manifest V3**: Fully compliant modern extension architecture.
- **💾 Quick Snippet Save**: Save code snippets with title, tags, and syntax whitespace preservation.
- **🔍 Fast Search**: Instant keyword filtering across all saved notes.

---

## 🚀 Installation & Testing

1. Open Chrome and go to `chrome://extensions/`.
2. Enable **Developer mode** toggle in top-right.
3. Click **Load unpacked** and select this directory.

Run unit tests:
```bash
npm test
```
